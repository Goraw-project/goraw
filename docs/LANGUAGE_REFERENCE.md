# Полный справочник по языку Goraw

Goraw — статически типизированный системный язык программирования, компилируемый в нативный машинный код через LLVM IR.

Язык объединяет:
- Минимализм и синтаксическую ясность **Go**;
- Строгий контроль над памятью и безопасностью указателей в духе **Rust** (через явные `unsafe`-блоки);
- Встроенную поддержку функциональных конвейеров (`|>`) и векторных математических интринзиков;
- Декларативную JIT-специализацию «на лету» поверх LLVM ORC JIT;
- Первоклассные срезы (`[]T`) и иммутабельные строки (`str`);
- Отказоустойчивую машиночитаемую диагностику для людей и LLM.

---

## 1. Система типов

Все типы в Goraw делятся на скалярные, составные и указательные:

### Скалярные примитивы
| Тип | Размер | Описание |
|---|---|---|
| `i8`, `i16`, `i32`, `i64` | 1, 2, 4, 8 байт | Знаковые целые числа |
| `u8`, `u16`, `u32`, `u64` | 1, 2, 4, 8 байт | Беззнаковые целые числа |
| `f32`, `f64` | 4, 8 байт | Числа с плавающей точкой (IEEE-754) |
| `bool` | 1 байт | Булево значение (`true`, `false`) |
| `void` | 0 байт | Тип отсутствия значения (для функций без возврата) |

### Первоклассные строки (`str`)
Тип `str` представляет собой иммутабельную UTF-8 строку, реализованную поверх среза байт `[]u8`:
```goraw
let s: str = "Hello, world!";
```

**Операции со строками:**
1. **Конкатенация (`+`)**:
   ```goraw
   let full = "Hello " + "World!";
   ```
2. **Срезы (Slicing)**:
   ```goraw
   let sub1 = s[0..5];   // "Hello"
   let sub2 = s[7..12];  // "world"
   let sub3 = s[7..];    // от 7 до конца
   let sub4 = s[..5];    // от начала до 5
   ```
3. **Сравнение (`==`, `!=`)**:
   ```goraw
   if s == "Hello, world!" { ... }
   ```
4. **Встроенные методы**:
   - `s.len() -> i64` — длина строки в байтах.
   - `s.is_empty() -> bool` — проверка на пустую строку.
   - `s.starts_with(prefix: str) -> bool` — проверка префикса.
   - `s.ends_with(suffix: str) -> bool` — проверка суффикса.
   - `s.clone() -> str` — создание глубокой копии в куче.

### Указатели и адресация
- `*T` — неизменяемый сырой указатель (const pointer).
- `*mut T` — изменяемый сырой указатель (mutable pointer).

Взятие адреса (`&x` или `&mut x`) абсолютно безопасно и разрешено в любом контексте. Однако **разыменование указателя (`*ptr`) и адресная арифметика разрешены исключительно внутри блоков `unsafe { ... }`**:
```goraw
let mut x = 42;
let p = &mut x;

unsafe {
    *p = 100;
}
```

### Срезы (`[]T`) и массивы (`[N]T`)
- **Срез `[]T`** — fat pointer, содержащий указатель на данные `ptr: *T` и размер `len: i64`.
- **Массив `[N]T`** — непрерывный фиксированный блок в памяти или на стеке:
```goraw
let arr: [4]i32 = [10, 20, 30, 40];
let slice: []i32 = arr[1..3];
```

## 2. Переменные и константы

### `let` и `let mut`
Переменные по умолчанию иммутабельны:
```goraw
let a: i32 = 10;        // неизменяемая
let mut b: i64 = 20;    // изменяемая
b += 5;
```
Тип переменной может выводиться автоматически:
```goraw
let msg = "Hello";      // тип str
let flag = true;        // тип bool
let count = 42;         // тип i32
```

### `const`
Константы вычисляются на этапе компиляции:
```goraw
const PI: f64 = 3.141592653589793;
const BUFFER_SIZE = 1024 * 64;
```

### `static`
Глобальные переменные программы:
```goraw
static COUNTER: i64 = 0;
```

## 3. Функции и соглашения о синтаксисе

### Объявление функций
Функции объявляются ключевым словом `fn`. Возвращаемый тип указывается через `->`:
```goraw
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

fn greet() {
    println("Привет!");
}
```

> **Диагностика синтаксических опечаток (E0028)**:
> Если пользователь по привычке от C++/TypeScript/Go напишет:
> - `fn main(): i32`
> - `fn main() > i32`
> - `fn main() => i32`
>
> Компилятор не падает и не зацикливается, а выдает четкую подсказку:
> `error[E0028]: для возвращаемого типа функции используется `->`, а не `:` / `>``.

### Внешние C-функции (`extern fn`)
Поддерживается полное сопряжение с C ABI и переменным числом аргументов (`...`):
```goraw
extern fn printf(fmt: *u8, ...) -> i32;
extern fn malloc(size: u64) -> *mut u8;
extern fn free(ptr: *mut u8);
```

## 4. Управление потоком выполнения

### `if` / `else if` / `else`
Круглые скобки вокруг условия необязательны, фигурные скобки тела обязательны:
```goraw
if x > 0 {
    println("Положительное");
} else if x == 0 {
    println("Ноль");
} else {
    println("Отрицательное");
}
```

`if` также может использоваться как выражение (тернарный оператор):
```goraw
let max_val = if a > b { a } else { b };
```

### Цикл `for`
Поддерживает три формы:
```goraw
// 1. Стандартный цикл со счетчиком в стиле Go
for i := 0; i < 10; i++ {
    println(i);
}

// 2. Цикл с предваряющим объявлением
let mut j = 0;
for j < 5; j++ {
    println(j);
}

// 3. Бесконечный цикл с break
for {
    if should_stop() { break; }
}
```

### Сопоставление с образцом (`match`)
```goraw
match code {
    200 => println("OK"),
    404 => println("Not Found"),
    500 => println("Internal Error"),
    _   => println("Unknown Code"),
}
```

## 5. Структуры и методы

### Объявление структур
```goraw
struct Point {
    x: f64,
    y: f64,
}

struct Node {
    id: i32,
    next: *mut Node,
}
```

### Методы (`impl`)
Методы группируются в блоках `impl`:
```goraw
impl Point {
    fn distance(&self, other: &Point) -> f64 {
        let dx = self.x - other.x;
        let dy = self.y - other.y;
        return (dx * dx + dy * dy).sqrt();
    }

    fn translate(&mut self, dx: f64, dy: f64) {
        self.x += dx;
        self.y += dy;
    }
}
```

## 6. Функциональные конвейеры (`|>`) и математика

Оператор `|>` передает левую часть как первый аргумент в правую функцию:
```goraw
fn double(x: f64) -> f64 { return x * 2.0; }
fn add_one(x: f64) -> f64 { return x + 1.0; }

let res = 5.0 |> double |> add_one; // (5.0 * 2.0) + 1.0 = 11.0
```

### Встроенные математические интринзики
Компилятор транслирует стандартные математические вызовы напрямую в быстрые SIMD/LLVM интринзики:
- `abs(x)` — абсолютное значение.
- `sqrt(x)` — квадратный корень.
- `min(a, b)`, `max(a, b)` — минимум / максимум.
- `clamp(val, min_val, max_val)` — ограничение диапазона.
- `pow(base, exp)` — возведение в степень.
- `floor(x)`, `ceil(x)` — округление вниз / вверх.
- `sin(x)`, `cos(x)` — тригонометрические функции.

## 7. Декларативная JIT-специализация

Goraw включает синтаксическую конструкцию `jit(args) { body }`, которая компилирует специализированный машинный код в рантайме под конкретные аргументы через LLVM ORC JIT:

```goraw
fn compute(factor: i64, val: i64) -> i64 {
    // При первом вызове генерируется специализированный нативный код под factor
    return jit(factor) {
        return val * factor + 42;
    };
}
```
Рантайм JIT ([runtime/goraw_jit.c](file:///P:/Goraw/runtime/goraw_jit.c)) автоматически кэширует скомпилированные функции и разворачивается рядом с исполняемым файлом.

## 8. Модульность и многофайловая сборка

Файлы импортируются директивой `import`:
```goraw
import "math_utils.gw";
import "models/user.gw";
```
Компилятор автоматически строит ациклический граф зависимостей, исключает повторные включения и сохраняет точные сопоставления номеров строк для диагностик.
