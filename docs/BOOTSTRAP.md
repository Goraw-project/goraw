# Бутстрап: компиляция LLVM+Clang на Goraw

Цель: Goraw компилирует переведённые из C++ исходники LLVM/Clang (`backend/*.gw`),
затем gorawc заменяет системный LLVM этими локальными `.gw`.

Подход **по данным**: гнать `gorawc` по корпусу, закрывать блокеры по убыванию частоты,
сверяться на малом образце (быстро, без полной ре-трансляции), коммитить пофично.

## Статус (итерации 1–11)

**Фаза 1 — парс (почти закрыта).** Расширенный замер (24 файла): **parse-clean 21/24 (~88%)**,
из них **5 компилируются в LLVM IR целиком**. Снято транслятором:
- octal-escape лексера; STL-шаблоны типов (`SmallVector`→`[]T`, `function<>`→`*mut u8`, …);
- имена `operator`/деструкторов (`sanitize_member_name`); рендер операторных вызовов
  (унарные/бинарные/compound как инфикс);
- дефолт/value-конструкция контейнеров (`non_struct_default`); типы-лямбды→opaque;
- graceful-placeholder для пустых подвыражений (`lift_or`); for с мультиinit (вынос);
- унификация свободных операторов; `const`→`static mut` при непостоянном init;
  `*const`-нормализация; CRT/qualified-typedef'ы.

**Фаза 2 — типы (стартовала сильно).**
- Режим **`GORAW_EMIT_ALL_TYPES=1`**: транслятор эмитит ТОЛЬКО определения всех
  struct/enum из заголовков (рекурсия в namespace, без функций/замыканий) + forward-
  заглушки `struct X {}` для неопределённых ссылок. Результат (lld/COFF):
  **622 struct + 175 enum, 0 ошибок, выдаёт LLVM IR**.
- **Проводка проверена**: backend-перевод функций + `import "types_<group>.gw"` →
  кросс-файловые типы разрешаются. MarkLive.gw: **34 → 15 ошибок**.

## Как сгенерировать модуль типов (пример, lld/COFF)

```bash
B=/p/llvm-build; LP=/p/Goraw/llvm-project
GEN="-I $B/include -I $B/tools/clang/include"
INC="-I $B/tools/lld/COFF -I $LP/lld/COFF -I $LP/lld/include -I $LP/llvm/include"
GORAW_EMIT_ALL_TYPES=1 goraw from-cpp $LP/lld/COFF/MarkLive.cpp -o types_lld.gw $GEN $INC
```
Затем в backend-`.gw`: `import "types_lld.gw";` → типы видны.

## Обновление (итерации 12–20)

- `std::function<R(Args)>` -> fn-указатель Goraw `fn(Args) -> R`; fn-дефолт -> `null`.
- **Каскадный фикс дедупа типов**: имя писалось в emitted_types в начале lift, но
  при раннем return None тип «занимался» и не заглушался -> E0020. Теперь запись
  при успешной эмиссии. + `union`-strip, `(*)`-типы, голые smart-ptr -> `*mut u8`.
  Модули типов по группам: **0–15 ошибок** (было ~51 у всех).
- `zeroed()`/`null` — валидный константный init для `static` (E0089 снят).
- desugared qualType -> резолв typedef'ов (`Statistic`->`TrackingStatistic`) и `auto`.
- **Сигнатуры функций в модуле типов**: `extern fn name(params) -> R;` для свободных
  функций (дедуп перегрузок), базовые типы пар/возврата -> referenced_types. volatile-strip.
  Модуль типов instcombine: **0 ошибок с 1409 сигнатурами**. Проводка MarkLive: 34 -> 15.

Текущее состояние модуля типов (на файл): struct+enum+заглушки + extern-fn-сигнатуры,
**0 ошибок**. Остаток combined — семантика тел функций (E0071 методы/квалиф., E0070).

### Метод-сигнатуры (не зашло, нужна фильтрация)

Попытка эмитить стабы методов `fn T::m(self,...) -> R { return zeroed(); }` (27727 шт)
регрессировала модуль типов 0 -> 51 (E0010). Паттерны к починке перед повтором:
пустой pointee `-> *mut ` (сложный/шаблонный возврат), утечки `operator new/delete`
в телах, шаблонные методы. Фильтровать по этим признакам или эмитить только простые.

## Осталось (Фаза 2 → 3)

1. **Семантика остатка (~15 на файл)**: замыкания/`std::function` (сейчас `*mut u8`
   + `.call()`), типы возврата методов (итерация `for x in obj.method()`), присваивание
   замыкания в `function<>`-поле. Нужны настоящие замыкания/fn-типы и сигнатуры методов.
2. **Официальная проводка**: генерить один модуль типов на группу (или общий) и
   автоматически проставлять `import`; собрать `backend/mod.gw` целиком.
3. **Полная ре-трансляция** фиксенным транслятором (память: гиганты ISelDAGToDAG/
   ISelLowering строго по одному — см. tools/regen_backend.sh, кап BIG_MAX).
4. **Фаза 3 — бутстрап**: вкрутить скомпилированные `.gw`-LLVM в gorawc вместо системного.
