# Mandatory Shadow Tests в Goraw

Система **Shadow-тестов** (теневых тестов) — ключевая архитектурная фича языка Goraw, разработанная для высоконадежной системной разработки и эффективного взаимодействия с LLM.

---

## 1. Концепция и мотивация

В традиционных языках тесты либо размазаны по отдельным файлам в подпапках `tests/`, либо требуют тяжелых фреймворков и макросов (`#[cfg(test)]`, GoogleTest, Catch2). Для разработчиков и AI-агентов это создает когнитивную нагрузку и риск рассинхронизации тестов с изменяемым кодом.

В Goraw тесты объявляются **рядом с функциями**, но подчиняются строгому жизненному циклу:
1. **Теневое присутствие (Shadow)**: код тестов живет в том же модуле, что и реализация, но **никогда не попадает в релизный бинарный файл**.
2. **Встроенный `assert`**: проверка утверждений разрешена исключительно внутри `shadow`/`test` блоков, гарантируя отсутствие непреднамеренных паник в релизном коде.
3. **Обязательная верификация (`--shadow=strict`)**: строгий режим проверки наличия тестов для каждой написанной функции.

---

## 2. Синтаксис объявления

Поддерживаются две формы объявления теневых тестов:

### Форма 1: `shadow <fn_name>` (привязка к функции)
Рекомендуется для модульных проверок функций:
```goraw
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

shadow add {
    assert add(2, 3) == 5;
    assert add(-4, 4) == 0;
    assert add(0, 0) == 0;
}
```

### Форма 2: `test "описание"` (комплексные сценарии)
Рекомендуется для интеграционных тестов или сценариев со сложным описанием:
```goraw
test "проверка факториала для граничных условий" {
    assert factorial(0) == 1;
    assert factorial(1) == 1;
    assert factorial(5) == 120;
}
```

## 3. Режимы сборки и выполнения

### 1. Релизная сборка (по умолчанию)
```bash
gorawc main.gw -o app.exe
```
Компилятор парсит блоки `shadow`, но при генерации кода (LLVM IR) полностью отбрасывает их. Накладные расходы на размер бинарника и производительность равны ровно **0 байт и 0 тактов**.

### 2. Режим прогона тестов (`--test`)
```bash
.\box.cmd gorawc main.gw --test
```
При передаче флага `--test` компилятор трансформирует программу:
1. Пользовательская функция `main()` временно изолируется.
2. Каждый блок `shadow` / `test` компилируется в изолированную тестовую функцию `__test_N() -> i64`.
   - Если все `assert` успешны — функция возвращает `0`.
   - Если `assert` падает — возвращается точный **номер строки упавшего assert**.
3. Компилятор на лету генерирует тестовый harness `main()`, последовательно запускающий все тесты и выводящий отчет:
```text
[ ok ] add
[ ok ] factorial

2 passed, 0 failed
```
При падении assertion:
```text
[FAIL] add (строка 8)
[ ok ] factorial

1 passed, 1 failed
```
Код завершения процесса равен числу упавших тестов.

### 3. Строгий режим верификации (`--shadow=strict`)
```bash
.\box.cmd gorawc main.gw --shadow=strict
```
Флаг `--shadow=strict` включает проверку полноты покрытия:
- Компилятор анализирует все функции программы (за исключением внешних `extern fn` и системного `main`).
- Если у функции отсутствует привязанный блок `shadow <name>` или `test "<name>"`, компиляция прерывается с ошибкой **E1200**:

```text
error[E1200]: функция `factorial` не имеет обязательного shadow-теста (--shadow=strict)
  --> main.gw:6:1
   | fn factorial(n: i64) -> i64 {
   | ^
   = hint: добавьте `shadow factorial { ... }` или `test "factorial" { ... }`
```

Режимы можно объединять:
```bash
# Проверка наличия всех тестов + немедленный запуск
.\box.cmd gorawc main.gw --shadow=strict --test
```

## 4. Полный пример из репозитория

Файл [examples/shadow_strict_demo.gw](file:///P:/Goraw/examples/shadow_strict_demo.gw):

```goraw
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

fn factorial(n: i64) -> i64 {
    let mut r: i64 = 1;
    for i := 1; i <= n; i++ {
        r *= i;
    }
    return r;
}

shadow add {
    assert add(2, 3) == 5;
    assert add(-4, 4) == 0;
}

shadow factorial {
    assert factorial(0) == 1;
    assert factorial(5) == 120;
}

fn main() -> i32 {
    return 0;
}
```

Запуск в контейнере под лимитом памяти 16 ГБ:
```bash
.\box.cmd gorawc examples\shadow_strict_demo.gw --shadow=strict --test
```
