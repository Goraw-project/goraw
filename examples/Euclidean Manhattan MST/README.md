# Manhattan Minimum Spanning Tree (Rectilinear MST in $\mathbb{R}^2$) in Goraw

Проект реализует алгоритм построения **Минимального остовного дерева на плоскости с манхэттенской метрикой (Manhattan / Rectilinear MST, $L_1$-метрика)** за **$O(N \log N)$** на системном языке программирования **Goraw**.

> **Метрика и терминология**:
> Задача рассматривает точки на двумерной плоскости ($\mathbb{R}^2$), соединённые ортогональными трассами (chip routing), где расстояние измеряется исключительно по $L_1$-норме (Манхэттенское расстояние). Алгоритм реализует **Manhattan MST** (Rectilinear MST), в отличие от евклидова остовного дерева (Euclidean MST, $L_2$-метрика).

---

## 1. Постановка задачи и ограничения

- **Дано**: $N$ процессоров (точек) на плоскости с целочисленными координатами $(x_i, y_i)$.
- **Метрика**: Манхэттенское расстояние $D(A, B) = |x_A - x_B| + |y_A - y_B|$.
- **Цель**: Найти связный ациклический граф (дерево) с минимальной суммарной длиной рёбер.
- **Ограничения**:
  - $N = 100\,000$ ($10^5$ точек).
  - Координаты точек: $x_i, y_i \in [-10^9, 10^9]$.
  - Лимит времени: **1–2 секунды**.
  - Лимит памяти: **256 МБ**.

### В чём сложность?
Полный граф между всеми парами точек содержит:
$$\frac{N(N - 1)}{2} \approx 5 \times 10^9 \text{ рёбер}$$
Алгоритмы Прима или Краскала «в лоб» требуют $O(N^2)$ операций и сотен гигабайт памяти, что приводит к гарантированному Time Limit / Out of Memory.

## 2. Теоретическая основа: алгоритм за $O(N \log N)$

Алгоритм основан на геометрической редукции Гибаса — Столфи (Guibas & Stolfi, 1983) и методе сканирующей прямой (Zhou, Shenoy, Nicholls, 2002):

1. **Разбиение на 8 октантов вокруг каждой точки**:
   Внутри любого октанта угол между лучами не превышает $45^\circ$. В манхэттенской метрике треугольное неравенство гарантирует: если точка $A$ ближе к $P$, чем точка $B$, ребро $(P, B)$ **никогда не войдёт в MST**, так как $D(A, B) \le D(P, B)$, и ребро $(P, B)$ будет максимальным в треугольнике $PAB$.
   Следовательно, для каждой точки достаточно оставить **лишь одного ближайшего соседа в каждом октанте**!

2. **Редукция до 4 проходов (полуплоскость $x \ge 0$)**:
   Поскольку граф ненаправленный, достаточно найти ближайших соседей в 4 октантах правой полуплоскости $\Delta x \ge 0$. Применяются 4 преобразования координат:
   - Проход 0: $(x, y)$ — октант $[\pi/4, \pi/2]$
   - Проход 1: swap $(x, y) \to (y, x)$ — октант $[0, \pi/4]$
   - Проход 2: negate $x \to (-y, x)$ — октант $[-\pi/4, 0]$
   - Проход 3: swap $\to (x, -y)$ — октант $[-\pi/2, -\pi/4]$

3. **Сканирующая прямая + дерево Фенвика (Fenwick Tree)**:
   - Условие октанта: $x_j \ge x_i$ и $y_j - x_j \ge y_i - x_i$.
   - Сортируем точки по убыванию $x$ (при равенстве — по убыванию $y$). Тогда условие $x_j \ge x_i$ выполняется автоматически.
   - Сжимаем координаты значений $z = y - x$.
   - В дереве Фенвика поддерживаем минимум $(x_j + y_j)$ на префиксах рангов.
   - Запрос префикса находит точку $j$, минимизирующую $(x_j + y_j) - (x_i + y_i) = D(i, j)$ за $O(\log N)$.

4. **Алгоритм Краскала + DSU**:
   - Число рёбер сокращается с $10^{10}$ до не более чем $4N = 400\,000$.
   - Сортировка $400\,000$ рёбер и СНМ (Disjoint Set Union) с эвристикой сжатия путей и ранговой эвристикой находят точное остовное дерево за считанные миллисекунды.

## 3. Архитектура и надежность реализации

```
examples/Euclidean Manhattan MST/
├── goraw.toml         # Манифест пакета Goraw
├── README.md          # Документация и математическое обоснование
└── src/
    └── main.gw        # Реализация алгоритма, IntroSort, BufferGuard, тесты
```

### Безопасность 64-битной арифметики (`i64`)
- Заданы строгие константы допустимого диапазона: `COORD_MIN = -10^9`, `COORD_MAX = 10^9`.
- Функция `validate_coordinates` валидирует входные данные на старте алгоритма.
- При координатах из $[-10^9, 10^9]$ разности координат не превышают $2 \times 10^9$, а максимальный вес MST $\le 4 \times 10^{14}$, что оставляет четырёхкратный порядок запаса до предела `i64` ($9.22 \times 10^{18}$).
- Безопасная функция `abs_i64` защищена от аппаратного переполнения на `INT64_MIN` (`-9223372036854775808`).
- Константа бесконечности `INF_DIST = 4 * 10^18` строго отделена от максимума `i64` и гарантированно превышает любые расстояния.

### Архитектура управления памятью (RAII BufferGuard)
Для исключения утечек памяти при любых аварийных выходах, паниках и ранних возвратах реализована идиоматичная для Goraw RAII-обёртка `BufferGuard` с методом `BufferGuard::drop(self)`. Компилятор Goraw гарантирует детерминированный вызов деструктора `free` при выходе из области видимости, полностью защищая кучу.

### Гибридная сортировка IntroSort (Гарантия O(N log N) без Stack Overflow)
Внедрён алгоритм **IntroSort** (гибрид QuickSort, InsertionSort и HeapSort):
1. **Median-of-Three pivot**: выбор медианы из начала, середины и конца отрезка для защиты от вырождения на упорядоченных массивах.
2. **Insertion Sort для малых диапазонов ($N \le 16$)**: эффективная сортировка вставками для коротких интервалов.
3. **HeapSort fallback при глубине рекурсии $> 2 \lfloor \log_2 N \rfloor$**: строгая гарантия времени худшего случая $O(N \log N)$ (невозможность деградации до $O(N^2)$).
4. **Tail-Call Optimization**: рекурсивный вызов всегда направляется в меньшую половину разбиения, а большая обрабатывается итеративно. Глубина стека вызовов **строго ограничена $\le \log_2 N \le 30$ кадрами**, что физически исключает Stack Overflow.

### Параметризованный движок без дублирования кода
Функция `solve_manhattan_mst_core` является единым источником истины для построения MST. Переключатель `use_pure_heap` позволяет запускать алгоритм как в гибридном режиме (IntroSort), так и в эталонном чисто-пирамидальном режиме (HeapSort), исключая дублирование логики sweep-line и DSU.

## 4. Сборка и запуск

### Запуск тестов (15 Shadow Tests)
```bash
goraw test -s
```
Или из корня репозитория:
```bash
.\box.cmd -s gorawc "examples\Euclidean Manhattan MST\src\main.gw" --test
```

### Сборка и запуск релизной версии ($N = 100\,000$)
```bash
goraw run --release
```
Или через изолированный контейнер `box`:
```bash
.\box.cmd -s gorawc "examples\Euclidean Manhattan MST\src\main.gw" -r --run
```
